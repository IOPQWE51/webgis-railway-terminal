# 花火数据年度切换手册

- 日期：2026-09-06
- 维护对象：`src/config/hanabiData.js`
- 消费方：花火情报局（`src/components/HanabiRadar.jsx`）、今日去这卡（`src/components/TodayCard.jsx`）

---

## 数据契约

每条大会的必填字段（`tests/today-card.test.js` 有契约测试守着，缺字段会红）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | number | 稳定数字 id，换年时可重新编 |
| `name` | string | 大会名（中文习惯译名） |
| `date` | string | **ISO 日期 `YYYY-MM-DD`**，燃放日；多日大会取首日 |
| `location` | string | 会场描述（情报局 tab 显示用） |
| `scale` | string | 发数规模（显示用） |
| `status` | `"confirmed" \| "planned"` | 已定档 / 计划中（显示用） |
| `lat` / `lon` | number | **燃放点近似坐标**（今日卡距离排序依赖；无坐标的大会今日卡看不见） |

## 年度切换步骤（约十分钟）

1. 替换 `HANABI_DATA` 数组为新一季数据（整组替换即可，不必逐条改）
2. 每条补齐 `lat/lon` —— 用燃放河川敷/会场的近似坐标即可，精度到小数点后 3-4 位足够（50km 半径排序不在乎几百米）
3. `npx vitest run tests/today-card.test.js` —— 契约测试（经纬度合法 + ISO 日期 + 非空名称）必须全绿
4. `npm run build` 通过后提交

**无需担心的**：今日卡只显示"今天起 7 天内"的大会（日期窗口过滤在 `TodayCard.jsx` 的 `nearbyPool`），旧年份数据过期后静默不上榜，不会推荐已办完的大会；花火情报局 tab 是全量列表，不受影响。
